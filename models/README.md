# Models

Fetched by `scripts/fetch-models.sh`; ignored by Git.

- `zinnia/`: Tegaki 0.3 Zinnia models for ja, zh_CN, zh_TW.
- `wagomu/`: Wagomu engine and models for comparison.

Model files and licenses are not part of this repository's source; the manifest
under `data/manifests/` pins their origin and checksums.
