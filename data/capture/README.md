# Capture target lists

Generated by `scripts/make_capture_list.py` under `data/capture/generated/`.
They are reproducible from the committed Tomoe corpora and a seed, so the
generated files are ignored by Git.

```sh
python3 scripts/make_capture_list.py --language zh_CN --limit 300 --seed 1
```

If a target list itself needs to be shared, commit it outside
`data/capture/generated/` and record why.
