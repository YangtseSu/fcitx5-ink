每一轮 20 个字，来自训练池；写完就可以停，想多写可以再来一轮。

为什么要收集

手写识别需要大量真实写法。训练池按常用标准字表覆盖：简体 3,500、繁体 4,808、日文 2,136 个常用字和假名；字序按使用频率排列。

训练池和评估集分开：评估集是每语言 300 个留出字，由维护者用不同书写者收集；同一书写者不会同时进入两边。

样本以 CC BY 4.0 发布，任何人都可以复用；项目代码以 GPL-3.0-or-later 发布。

隐私与许可

不收集姓名、邮箱或原始 IP。浏览器里只保存一个随机书写者编号，用来把同一人的样本分组；IP 只以加盐哈希形式用于限流。

样本包含目标字、笔画坐标、书写语言和匿名编号。请不要书写含有个人信息的内容。想删除自己的样本，请通过 GitHub 联系。
